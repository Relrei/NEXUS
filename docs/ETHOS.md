# NEXUS 開発エートス（進め方の哲学・常に効かせる）

2026-06-16 ユーザー指針。実装・デザインの全判断はこの4つを通す。

## 1. 見た目＝青みのない漆黒（Claudeの癖を矯正）
- デフォルトの「青よりの黒」(slate / blue-black)を**使わない**。
- **ニュートラルな真の黒（#0a0a0a, neutral-*）＋白**。色は機能に必要な所だけ、最小限。
- 選択/強調は青でなく**白系**（SpaceX的モノクローム）。

## 2. SpaceX＝洗練 ＋ 不要物の排除
- 飾りを足さない。各UI要素に**存在理由**を要求。無いなら消す。
- 余白・整列・タイポで成立させる。装飾でごまかさない。

## 3. Linus＝動く必要なものだけ認める
- 使われていないコード/依存/抽象は**即削除**（例: Freeboard/Starfield/未使用CSSを削除済）。
- 仮説より動くもの。まず動かして計測→改善。複雑さは敵。

## 4. base44創業者＝一人で扱いこめる
- 個人が**全体を把握し改造できる**軽さ。依存と複雑さを最小に。
- 重い基盤・ブラックボックスを避ける。ローカルファースト・自前完結（[[KIMI_design_brief]] と整合）。
