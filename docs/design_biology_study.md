# NEXUS デザインスタディ — 生物学的テーマ（エヴァ由来）の探索

作成: 2026-06-16 / デザインリサーチ（探索のみ・実装はしない）

先生の方向性「**生物学を使ったデザインってどうかな（エヴァ由来）**」を真剣に検討した記録。
結論を先に言うと **推奨は (B)＝切替可能な第2テーマとして「生体モード」を追加** + 一部のメタファだけ
（Cold/Hot の拍動・近接リンクの菌糸）を宇宙テーマにも逆輸入する、です。理由は本文末尾。

---

## 0. 現状UIの要約（コードから把握）

- `Freeboard.tsx`: 無限キャンバス。ワールド層を `translate3d + scale` でパン/ズーム。背景は
  `nexus-bg`（暗いラジアルグラデ）＋巨大な `border-radius:50%` の地球ハロー（視差0.03）＋`Starfield`。
- `Starfield.tsx`: canvas 2層（far 220点 / near 90点）を **一度だけ描画** し、以後はCSS translateで
  視差移動するだけ＝毎フレーム再描画しない軽量設計。**これは死守すべき性能規律**。
- `ItemCard.tsx`: `.glass`（白4.5%＋blur14px）＋ `rounded-2xl`、上端に種別アクセントバー
  （メモ=emerald / リンク=sky / 画像=fuchsia / ファイル=amber）。`tint` で淡い種別色。
- 検索: 非該当カードを `opacity-15` に落として、該当だけ「その場で点灯」＝**空間記憶を壊さない**。
- Cold/Hot: `freshness` フラグ。Hot は炎アイコン。`locked`（確定=鍵）は sky のリング。
- データモデル(`db.ts`): Item に `x,y`（ワールド座標）、`hash`（重複検出）、content-addressed な
  blob pool。線に中身を流さない純粋設計。

要するに今は **「軌道上のミッションコントロール」＝静的で整然・高級・冷たい青** のトーン。

## 1. 比喩の適合性 — 生物学はNEXUSの本質に噛み合うか

NEXUSの本質を4語で言うと **収集→束ね→梱包 / 確定で再調査を断つ / 倉庫(Cold)中心 / 完了条件で有限化**。
これに対して候補メタファを「噛み合い度」で採点する。

| 生物比喩 | 噛み合い | 評価 |
|---|---|---|
| **菌糸ネットワーク（mycelium）** | ◎ | **本命**。地下に広がり、養分(素材)を集めて運び、必要な所で**子実体(きのこ)＝Outputに結実**する。「集めて→束ねて→一点で梱包して吐く」が菌類のライフサイクルそのもの。リンク=菌糸、Output=結実、が無理なく対応する。 |
| 神経網/シナプス | ○ | リンクの発火・点灯と相性良。ただし神経は「考える道具」の比喩であり、NEXUSは**考える道具ではなく梱包する道具**と明言している（design_brief末尾）。本質と少しズレる。アクセント要素に留めるべき。 |
| 細胞/胞子・培養皿 | ○ | カード=細胞、フリーボード=培養皿(ペトリ皿)、自動配置(phyllotaxis)=コロニーの自己組織化、は綺麗に効く。ただし「成長して増殖する」感は倉庫(静的・確定)とやや逆。**増殖でなく休眠/活動の対比**として使うのが正解。 |
| 生きたアーカイブ/有機体 | ◎(態度) | 「倉庫＝死蔵」でなく「生きて呼吸している保管庫」という**気分**は、ADHDの「放置して腐らせる」恐怖の逆＝心理的に効く。ただし“生きてる＝勝手に動く”はADHDの空間記憶を壊すので**動きは最小**に。 |

### 宇宙テーマ vs 生体テーマ（本質適合の比較）

- **宇宙(現状)**: 「散らばった素材を一望できる夜空／星座」。**俯瞰・整然・確定**の気分に強い。
  Cold倉庫(永久・不変)＝星は動かない、と相性が良い。**冷たく落ち着くのが長所**。
- **生体(エヴァ)**: 「集めた素材が**運ばれ・束ねられ・結実する**プロセス」。**動詞(集める/束ねる/吐く)**に強い。
  Source→Transform→Output の**流れ**を語るのに向く。**温かく・蠢く・生々しいのが長所**。

→ どちらも本質の別の面を照らす。**宇宙＝倉庫の静（在庫の一望）／生体＝梱包の動（流れと結実）**。
NEXUSは静(Cold倉庫)が土台だが、最大の独自性は動(梱包Output)。よって
**「土台は宇宙のまま、梱包機能を作る時に生体の語彙が効く」** というのが正直な結論。今すぐ全面置換ではない。

## 2. 視覚言語 — エヴァ由来トーンを“上品に”落とす

エヴァの生体感の核は「**暗い体液の中で、半透明の膜越しに、何かが脈打って光っている**」。
気持ち悪さ寸前の美。これをUIに落とす時の鉄則は **「色は生体・構造はミニマル」**。
ベタな血肉グロにすると道具として使えない。**8〜9割は今の暗さを維持し、アクセントだけ生体色**にする。

### 配色案（HEX）

```
背景・体液         #07060a  (今の #05070d より僅かに赤に寄せた漆黒。青みを抜く)
深層グラデ上        #1a0e12  (暗い赤紫＝静脈血の底)
深層グラデ下        #0d1014  (僅かに緑がかった暗部＝LCL/培養液)
膜(ガラス置換)      rgba(255, 90, 70, 0.045)  ＋ blur  (半透明の生体膜)
膜の縁             rgba(255, 120, 90, 0.14)            (うっすら発光する細胞膜)
─ アクセント(生体) ─
コア・オレンジ      #ff6b3d  (エントリープラグ/生体の主色。発火・拍動)
血漿レッド          #e23c4e  (Hot＝活動・警告寄り)
ATフィールド橙黄    #ffb347  (確定/結実のグロー)
神経シアン残し      #5fd0c8  (神経シナプスの青緑。今のsky #7cc4ff の生体版)
胞子バイオレット    #9d6bd8  (画像種別。今のfuchsiaの落ち着き版)
```

ポイント:
- **今のシアン#7cc4ffを全部オレンジにしない。** 生体は「暖色(肉)×寒色(神経/培養液)」の対比でこそ生々しい。
  寒色を残すと“上品な生体”、全部暖色にすると“安いグロ”になる。
- 種別色は色相を保ったまま **彩度を1段落とし、暗部に沈める**（今のtintは0.07〜0.08で既に良い塩梅）。

### 形・質感・動き

- **形**: `rounded-2xl`(16px) → **非対称な有機曲線**。`border-radius: 40% 60% 55% 45% / 50% 45% 55% 50%`
  のような「細胞っぽい不定形角丸」を**ごく僅か**に（やりすぎると読みにくい）。カード自体は矩形を保ち、
  **角の丸みと縁のグローだけ生体化**が安全。
- **質感**: `.glass`(白blur) → **膜(membrane)**。`backdrop-filter: blur` は維持しつつ、縁に
  内側へ向かう薄いグラデ（`inset` シャドウ）で「膜が張っている」感。ノイズテクスチャを2〜3%だけ重ねて
  「乾いたガラス」→「湿った膜」に。
- **動き**: **拍動(pulse)**。Hotカードだけ縁のグローが心拍のように 1.2s で明滅。**全カードを動かすのは厳禁**
  （ADHDの空間記憶＝静止が前提）。動くのは「今アクティブな所」だけ。

## 3. マッピング（NEXUS概念 ↔ 生物）

| NEXUS | 生物比喩 | UI表現 |
|---|---|---|
| アイテム(カード) | **細胞 / 胞子** | 膜質の不定形カード。休眠中は縁が暗い。 |
| Cold(倉庫・永久) | **休眠 / 芽胞(spore)** | 彩度低・縁グロー消灯・完全静止。「眠っている在庫」。 |
| Hot(TTL・再取得) | **活動細胞 / 代謝中** | 縁が #e23c4e で**ゆっくり拍動**。「まだ生きて餌を要求している」。 |
| locked(確定・鍵) | **石化 / 結晶化した核** | #ffb347 の固いリング＋拍動停止。「もう変わらない＝代謝を止めた」。鍵より生体的に正しい。 |
| リンク(将来) | **菌糸(hypha) / シナプス** | 近接した細胞間に細い菌糸が伸びて繋がる。発火時だけ養分が流れる光。 |
| 検索 | **走光性 / 発火(firing)** | 該当細胞が**発火して光る**（今の点灯＝既にこの比喩に合致）。非該当は暗いまま。 |
| Output(梱包) | **結実 / 子実体(きのこ) / 分泌** | 集めた素材(菌糸)が一点に集約し**実を結ぶ**。完了条件＝結実に必要な養分が揃った状態。 |
| 必要ポート=完了条件 | **結実条件(栄養・湿度が揃う)** | ポートが全部満たされると子実体ノードが「熟す(色づく)」＝視覚的な完了。 |
| フリーボード | **培養皿(ペトリ皿) / 組織(tissue)** | 暗い培養液の上にコロニーが散る。phyllotaxis自動配置＝コロニーの自己組織化。 |
| 重複検出 | **免疫 / 自己非自己認識** | 「もう持ってる(自己)」を弾く＝免疫の比喩。トーストを「拒絶反応」風に。 |

**特筆**: `locked=石化/結晶化` と `Hot=拍動` の対比は、現行の「鍵 vs 炎」より**意味的に強い**。
「生きてる(Hot)＝代謝し餌を欲する」「確定(locked)＝代謝を止めて固まった」は、Cold/Hot/確定の
**3状態を一本の生命メタファで説明**できる。これは生体テーマ最大の収穫。

## 4. インタラクションの新規性（斬新さ・ただしADHD核を壊さない）

ADHDの核＝**①空間記憶（カードは動かない）②可視化③確定で再調査を断つ④完了条件**。
これを壊さずに「気持ちよさ・斬新さ」を足せる候補:

1. **近接で繋がる菌糸（◎ 新規性高・核を壊さない）**
   - 2枚のカードを手で近づけると、間に菌糸が**にゅっと伸びて接続候補**になる。離すと枯れる。
   - 「リンクを作る」が**ドラッグで物理的**になる＝Milanoteのコネクタより直感的で気持ちいい。
   - カードは自分で動かない（①死守）。動くのは菌糸という線だけ。
2. **拍動するHot（◎ 可視化強化）**
   - Hotだけ縁が心拍。「再取得対象がまだ生きている」が**一目**で分かる。Coldは完全静止＝静けさが際立つ。
3. **結実するOutput（◎ 完了条件の可視化＝NEXUS最大の出口）**
   - Outputノードに必要ポートを刺すと、満たされた分だけ子実体が**育つ/色づく**。全部揃うと「熟した」表示＝
     「揃った」の終点(④)を**生命的な達成感**で出す。梱包＝結実は比喩として完璧。
4. **発火検索（既存の延長）**
   - 今の「該当だけ点灯」を、神経の発火（一瞬強く光ってから安定グロー）に演出強化。**重くしない**。
5. **避けるべき新規性（ADHD核を壊す）**
   - ✗ 自己組織化で**勝手にレイアウトが動き続ける** → 空間記憶が崩壊。配置は確定したら固定。
   - ✗ 細胞が**増殖/分裂アニメ** → 倉庫(確定・不変)と矛盾。増殖は禁止、状態変化だけ。

## 5. 実装現実性（最小コストで生体感を出す段階プラン）

今のスタック（React + Canvas + CSS / Tailwind v4）で**重くせず**段階的に出せる。
性能規律＝**「全カードを毎フレーム動かさない」「canvasは一度描画＋CSS変形」** を維持する。

### Phase 1: 配色だけ（コスト最小・1ファイル・即生体感）
`src/index.css` を差し替えるだけ。`.glass`/`nexus-bg` の値を生体トーンへ。**JSは無改造**。
```css
/* nexus-bg: 青いグラデ → 暗い体液（赤紫×培養緑） */
.nexus-bg {
  background:
    radial-gradient(1200px 600px at 80% -10%, rgba(200, 60, 50, 0.10), transparent 60%),
    radial-gradient(900px 500px at 10% 110%, rgba(90, 30, 120, 0.12), transparent 60%),
    #07060a;
}
/* glass: 乾いたガラス → 湿った膜 */
.glass {
  background: rgba(255, 90, 70, 0.040);
  border: 1px solid rgba(255, 120, 90, 0.12);
  backdrop-filter: blur(14px);
}
.glass-hover:hover {
  background: rgba(255, 120, 90, 0.07);
  border-color: rgba(255, 140, 90, 0.30);
}
```
これだけで「青い宇宙」→「赤暗い生体腔」に化ける。**5分・ゼロリスク**。

### Phase 2: 拍動するHot ＋ 確定の石化（CSSアニメ・カードはDOMのまま）
`ItemCard.tsx` のクラスに状態別を足す（JS最小）。`@keyframes pulse` を1個追加。
```css
@keyframes membrane-pulse {           /* Hotだけに付与。GPU合成(opacity/box-shadow) */
  0%,100% { box-shadow: 0 0 0 1px rgba(226,60,78,0.25), 0 0 14px rgba(226,60,78,0.10); }
  50%     { box-shadow: 0 0 0 1px rgba(226,60,78,0.55), 0 0 22px rgba(226,60,78,0.28); }
}
.hot   { animation: membrane-pulse 1.6s ease-in-out infinite; }
.locked-bio { box-shadow: 0 0 0 1px rgba(255,179,71,0.6); }  /* 拍動なし=石化 */
```
- diff方針: `ItemCard` の最外 div に `item.freshness==='hot' && 'hot'` / `item.locked && 'locked-bio'`。
- **拍動するのはHotだけ**＝同時に動く要素は数枚に限定 → 性能影響ほぼ無し。

### Phase 3: 背景を星空 → ゆらぐ膜/細胞（Starfield改 or 置換）
2案。**軽い方(A)を推奨**。
- **(A) 星をそのまま“胞子/微生物”に再配色**（最小）: `Starfield.tsx` の `fillStyle` を
  `rgba(255, 150, 110, a)` 系に変えるだけ。粒の色が変わるだけで「培養液中の胞子」に見える。**1行**。
- (B) 細胞ノイズ膜: 静的な細胞ノイズ画像(Voronoi)を1枚 `background` で敷き、CSSで超低速ドリフト
  (`@keyframes` translateを30s)。**画像1枚＋CSSのみ＝毎フレーム計算なし**。canvasアニメは避ける。
- 地球ハロー(`Freeboard`内の巨大円)は **核(nucleus)/卵** として残せる。色を赤橙に変えるだけで流用可。

### Phase 4: 近接菌糸（要新規・将来 / リンク機能と同時）
- AUTORUNログ通り「**意味のあるリンク機能ができてから**」。フェイク線は嘘になるので今は描かない。
- 実装は Freeboard のワールド層に **SVG 1枚**を重ね、近接ペアにだけ `<path>` を引く（ベジェ）。
  描く線は近接時だけ＝**常時数本**。重くない。菌糸の“伸びる”演出は `stroke-dashoffset` アニメ。

### テーマ切替の実装（推奨Bのため）
- `<html data-theme="cosmos|bio">` を1属性。CSSを `:root` と `[data-theme="bio"]` で上書き。
  **JSロジック・データモデル・座標は一切変えない**＝完全に皮だけ。トグルは設定に1個。リスクゼロ。

```css
:root            { --bg:#05070d; --accent:#7cc4ff; --hot:#f59e0b; --glass:rgba(255,255,255,.045); }
[data-theme=bio] { --bg:#07060a; --accent:#ff6b3d; --hot:#e23c4e; --glass:rgba(255,90,70,.040); }
```
（現行の即値HEXを段階的に `var(--…)` へ寄せれば、両テーマが1つのCSSで共存できる。）

## 7. 結論と推奨

### 推奨: **(B) 切替可能な第2テーマ「生体モード」として追加** ＋ 一部メタファは宇宙にも逆輸入

立場をはっきり取る。**(A)全面置換はしない。(C)却下もしない。Bを推す。** 理由:

1. **本質適合は「引き分け、ただし役割が違う」**（§1）。宇宙＝倉庫の静(在庫一望・確定)、
   生体＝梱包の動(集める→結実)。NEXUSの土台は静(Cold倉庫)なので、**既定は宇宙のまま**が安全。
   だが最大の独自性は動(Output梱包)で、ここは**生体語彙(結実/必要養分=完了条件)が圧倒的に効く**。
   片方に殺すのは惜しい。両立させるBが最も情報量が多い。

2. **(A)全面置換のリスク**: 赤暗い生体腔は「集中して長時間こもる作業場」としては
   宇宙の青の方が疲れにくい人が多い。ADHDの落ち着き要件＝今の calm を捨てるのは賭け。
   置換は**気分次第で戻れない**＝先生の好みが割れたら詰む。Bなら1クリックで戻せる。

3. **(C)却下しない理由**: 「Cold=休眠/Hot=代謝/locked=石化」を一本の生命メタファで貫けるのは
   現行の「鍵/炎」混在より**意味的に強い**（§3特筆）。これと「近接菌糸リンク」「結実Output」は
   斬新さ要件(§4)に直球で応える、本当に良い鉱脈。捨てるのは損。

4. **実装コストが極小**（§5）。Bは `data-theme` 属性＋CSS変数だけで、JS/データ/座標は無改造。
   性能規律(canvas静的・全カード非アニメ)も完全に守れる。**やらない理由がない安さ**。

### 具体的に何をやるか（順序）
1. **今すぐ（5分）**: §3の状態メタファだけ**宇宙テーマにも逆輸入** — Hotを拍動、lockedを石化リングに。
   テーマと無関係に意味が強くなる。これは無条件でやる価値あり。
2. **次（Phase1+2をbioテーマとして）**: `data-theme="bio"` を追加し、配色＋膜＋拍動を生体版で用意。
   設定にトグル1個。先生が両方を実機で見比べられる状態を作る＝**意思決定を実物でできる**。
3. **将来（Phase4）**: リンク機能を作る時に「近接菌糸」と「結実Output」を実装。ここで生体テーマが
